# Life is Travel

Сайт с авторскими прогулками и маршрутами по городам.

## GitHub Pages

1. Создайте новый репозиторий на GitHub, например `life-is-travel`.
2. Загрузите файл `index.html` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Branch: **main**, Folder: **/(root)**.
6. Нажмите **Save**.

После публикации сайт будет доступен по адресу вида:
`https://USERNAME.github.io/life-is-travel/`

Все стили и JavaScript находятся внутри `index.html`, поэтому дополнительных файлов не требуется.
